For CSV Editor (PyQt format)
- Backspace undo and redo at cell level
- Ctrl c (Copy) and Ctrl v (Paste) at cell level (For single / multiple cell copy -> multi cell paste)
- Save CSV (More effective with Ctrl s)
- Zoom in (Ctrl +) and Zoom out (ctrl -)
- Remove Duplicates (as the name describes)
- Missing Only (as the name describes)
- Add row(s) / column(s)
- Delete Row(s) / column(s)
- Cell(s) select Copy / Delete
- Non-case sensitive search for both search bars with row numbers
- Column header editable
- Find Next, Previous match in pdf
- Up / down navigation key to move to the beginning / end of the content and ctrl up / down navigation to select content accordingly in both search bars and cells
(except for multi line content within cells, where up down navigation don't work but selecton work)
- Clean multilines button to clean lines with unnecessary line breaks, within cells
- Validate Answers and Validate Structure to edit, add or remove any redundant data
